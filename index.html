Why SpotShift

왜 필요한가요?

장시간 핫스팟을 켜두면 IP가 고정되어 접속 제한·차단이 생길 수 있습니다. SpotShift가 IP를 주기적으로 바꿔 이를 방지합니다.

주기 자동 변경

10분~24시간 사이 원하는 주기를 설정하면, 핫스팟이 켜진 동안 IP를 자동으로 바꿉니다.

네트워크 자동 복원

IP 변경 후 모바일 데이터와 핫스팟을 원래 상태로 되돌립니다. 에어플레인 폴백까지 지원해 어느 기기에서도 안정적으로 동작합니다.

무루트 · 서버 없음

루트 권한이 필요 없습니다. Shizuku만 있으면 동작하며, 모든 처리가 기기 안에서만 이뤄져 데이터가 외부로 나가지 않습니다.

Install Guide

설치 방법 — 4단계

Play 스토어에 올라가지 않은 독립 앱이라 다운로드~설치 과정이 조금 있습니다. 하나씩 따라 하시면 5분 안에 끝납니다.

1

Shizuku 앱 설치 필수

SpotShift는 권한이 없는 앱으로는 통신을 바꿀 수 없어, 무루트 권한 시스템인 Shizuku를 함께 사용합니다. 아래 중 편한 방법으로 Shizuku를 설치하세요.

  • Play 스토어: Shizuku (moe.shizuku.privileged.api) 검색 후 설치
  • GitHub (스토어 없이): RikkaApps/Shizuku 릴리즈에서 APK 다운로드
2

Shizuku 활성화 무선 디버깅 방식

갤럭시(One UI) 기준이며, 다른 기기도 경로만 다를 뿐 순서는 같습니다.

  1. 개발자 옵션 켜기 — 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드 번호를 7번 탭 ("개발자 모드가 켜졌습니다")
  2. 설정 → 개발자 옵션 → USB 디버깅 ON
  3. 설정 → 개발자 옵션 → 무선 디버깅 ON → (팝업이 뜨면 허용)
  4. Shizuku 앱 실행 → "무선 디버깅으로 시작" 탭 → 다음 화면의 안내대로 페어링
  5. 페어링 코드 입력 — 설정 → 개발자 옵션 → 무선 디버깅 → 페어링 기기 쌍 연결에서 코드 확인 후 입력 → "항상 허용" 체크
  6. Shizuku 화면 상단이 "Running"이 되면 완료 (부팅 후에는 Shizuku 앱을 다시 열어 재시작해 주세요)
💡 참고: ADB 케이블로 PC가 있다면 더 간단합니다 — PC에서 adb pair 없이 adb install 후 adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh 방식도 사용 가능합니다.
3

SpotShift APK 다운로드 + 허용

이 페이지의 APK 다운로드 버튼을 눌러 app-release.apk를 받으세요. Play 스토어가 아니므로 "알 수 없는 소스" 허용이 필요합니다.

  1. 다운로드 페이지에서 app-release.apk 다운로드 (한국·해외 어디서나 접속 가능)
  2. 다운로드 완료 알림에서 APK 탭 → "이 앱을 설치할 수 없습니다" 안내가 뜨면 "설정" 버튼 탭
  3. 갤럭시 경로: 설정 → 생체 인식 및 보안 → 기타 보안 설정 → 알 수 없는 앱 설치 → 사용 중인 브라우저(Chrome 등) 선택 → "이 앱 허용" ON
  4. 다시 APK 탭 → 설치 → 완료되면 열기
🔒 안전 안내: "알 수 없는 소스 허용"은 선택한 브라우저 하나에만 적용됩니다. 허용 후에도 app-release.apk 외 출처 불명 APK는 설치하지 마세요. 정식 서명(릴리즈 키)으로 빌드된 파일입니다.
4

SpotShift 시작 + 권한 연결

  1. 앱 실행 → 하단 설정 탭 → "권한 요청" 탭 → Shizuku 권한 다이얼로그에서 "항상 허용"
  2. 설정 탭이 "연결됨"으로 바뀌면 성공
  3. 홈에서 변경 주기 설정 (10분~24시간) → 셀룰러 전용·건너뛰기 등 원하는 옵션 ON
  4. 기기의 핫스팟을 켜고 홈의 자동 변경 시작 토글 ON
  5. 설정한 시각마다 IP가 자동 변경됩니다 — 상태 알림과 홈 화면에서 예상 변경 시각을 확인하세요
🌏 해외(일본 등) 사용: 이 페이지는 한국·일본 어디서나 접속·다운로드됩니다. 로밍 중이거나 일본 신주쿠 같은 Wi-Fi 밀집 지역에서도 동일한 방법으로 설치하면 그대로 동작합니다. IP 변경은 로컬에서 이뤄지므로 통신사/로밍 상태와 무관합니다.
FAQ

자주 묻는 질문

핫스팟을 껐다 켜도 되는데, 왜 이 앱이 필요한가요?
직접 껐다 켜면 IP가 바뀌지 않을 때가 많고(재할당이 항상 이뤄지지 않음), 잠깐이라도 연결이 끊깁니다. SpotShift는 모바일 데이터를 껐다 켜 IP 재할당을 강제하고, 완료 후 핫스팟을 자동 복원해 연결 중단을 최소화합니다.
루트 없이 어떻게 통신을 바꾸나요?
Shizuku가 셸 권한을 빌려주고, SpotShift가 이를 통해 시스템 명령(svc data disable/enable)을 실행하는 방식입니다. 실패 시 에어플레인 모드 전환으로 폴백합니다.
IP 변경 중 핫스팟 연결이 끊기나요?
네, 변경 순간 수 초간 끊기며 이후 자동으로 원래 상태로 복원됩니다. 데이터 재연결을 먼저 시도해 끊김 시간을 최소화합니다.
배터리나 데이터 사용량에 영향이 있나요?
IP 변경은 수 초간의 데이터 전환일 뿐이라 데이터 추가 소모는 거의 없습니다. 백그라운드 폴링 없이 설정된 시각에만 동작해 배터리 영향도 미미합니다.
앱 업데이트는 어떻게 받나요?
같은 GitHub 릴리즈 페이지에서 새 버전 APK를 받아 설치하면 됩니다. 같은 릴리즈 키로 서명되므로 기존 설정과 데이터가 유지된 채 업데이트됩니다.
이 앱은 어떤 데이터를 수집하나요?
아무것도 수집하지 않습니다. 서버가 없고 모든 처리가 기기 안에서만 이뤄집니다. 네트워크 명령 실행 권한(Shizuku)만 사용합니다.
