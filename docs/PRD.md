# PRD.md — SpotShift (핫스팟 IP 변환기) 요구사항 정의서

> 버전: v1.0 (2026-08-16) · 플랫폼: Android · 상태: 초안

## 1. 제품 개요

- **제품명**: SpotShift
- **한 줄 정의**: Android 기기를 핫스팟으로 사용하면서 일정 주기마다 IP를 자동 변경하고, 모바일 네트워크와 핫스팟을 자동 복원하는 네트워크 제어 앱
- **타겟 사용자**: 핫스팟을 장시간 운영하며 IP 변동이 필요한 사용자 (원격 작업, 캠핑/차박 네트워크 운영, 크롤링/테스트, 일시적 차단 회피)

## 2. 핵심 가치 (차별화)

1. **핫스팟 연결 유지 + 주기적 IP 자동 변경** — 경쟁 앱은 IP 변경 또는 핫스팟 제어 중 하나만 제공
2. **핫스팟 자동 복원 특화** — IP 변경 후 SSID/비밀번호 완벽 복원, 연결 기기 자동 재연결 유도 UX
3. **스마트 스케줄링** — 단순 타이머가 아닌 배터리 잔량·시간대·네트워크 품질 기반 조건부 실행

## 3. 기능 요구사항

### 3.1 핵심 (P0)

| ID | 기능 | 설명 | 승인 기준 |
|---|---|---|---|
| F-01 | 주기적 IP 자동 변경 | 설정 주기(분/시간/특정 시각)마다 IP 변경 실행 | TC-01 |
| F-02 | 에어플레인 토글 기반 IP 갱신 | Shizuku로 에어플레인 ON/OFF 후 IP 재조회 | TC-01 |
| F-03 | IP 변경 검증 | ipify 조회로 이전/새 IP 비교, 성공/실패 판정 | TC-01 |
| F-04 | 재시도 로직 | 실패 시 재시도(기본 2회) + 간격 설정 | TC-02 |
| F-05 | 핫스팟 재시작 폴백 | 에어플레인 실패 시 핫스팟 OFF/ON 후 IP 검증 | TC-03 |
| F-06 | SSID/비밀번호 자동 복원 | 핫스팟 재시작 후 기존 설정 복원 확인 | TC-03 |

| ID | 기능 | 설명 | 승인 기준 |
|---|---|---|---|
| F-10 | 배터리 조건 | 배터리 잔량 특정 % 미만이면 실행 보류 | TC-04 |
| F-11 | 시간대 조건 | 지정 시간 구간에서만 실행 | TC-04 |
| F-12 | 네트워크 품질 조건 | 신호 강도/네트워크 상태 확인 후 실행 판단 | TC-04 |

### 3.3 부가 (P1~P2)

| ID | 기능 | 설명 |
|---|---|---|
| F-20 | 수동 실행 | 대시보드 버튼으로 즉시 IP 변경 |
| F-21 | 변경 기록 | 성공/실패/재시도/이전IP/새IP/시각/소요시간 이력 |
| F-22 | 연결 기기 표시 | 핫스팟 연결 기기 수 (가능 시 목록) |
| F-23 | 포그라운드 서비스 | 앱 종료 후에도 스케줄 유지 + 상시 알림 |
| F-24 | Quick Settings 타일 | 시작/정지 빠른 토글 |
| F-25 | 클라이언트 재연결 유도 | IP 변경 후 "기기 자동 재연결 안내" 카드/알림 |
| F-26 | Shizuku 상태 가이드 | 연결 안 됨 시 설정 단계 안내 화면 |
| F-27 | 삼성 배터리 예외 안내 | 백그라운드 종료 방지 설정 안내 |

## 4. 비기능 요구사항

- 콜드 스타트 ≤2.0s, IP 변경 사이클 ≤30s (성공 시)
- 포그라운드 서비스 메모리 ≤80MB
- 다크 모드 기본 + 라이트 지원, 텍스트 명암비 ≥4.5:1
- 터치 타겟 ≥48dp
- 무루트 (Shizuku만) — 루트 사용자도 동일 동작
- 통신사 IP 정책은 외부 요인 — 변경 실패 시 명확한 실패 알림과 재시도 안내

## 5. 제약/리스크

| 리스크 | 대응 |
|---|---|
| 통신사가 동일 IP 재할당 | 재시도 + 폴백 + 실패 명시 알림 (숨기지 않음) |
| 삼성 백그라운드 종료 | 포그라운드 서비스 + 배터리 예외 안내 |
| Shizuku 미설치/미실행 | 온보딩 가이드 + 상태 카드 |
| 일부 기기에서 TetheringManager 리플렉션 불일치 | 기기별 실패 로그 + 지원 기기 안내 |

## 6. 아이콘 요구사항

- 원형 안에 Wi-Fi 신호 파장 + 화살표 순환 마크 (IP 순환 의미)
- 심플·직관적, 다크 블루 배경 + 하늘색 파장 + 초록 순환 화살표
- mipmap 전체 사이즈 (48/72/96/144/192)

## 7. 대상 플랫폼

- Android 8.0+ (minSdk 26), targetSdk 35
- 최적 환경: Android 11+ (Shizuku 무선 디버깅 가능) — S22 (Android 12+) 기준 검증
