# PLAN_v0.7_android.md — SpotShift 테더링 공유기화

> 버전: v0.7 계획 (2026-10-11) · 플랫폼: Android · 작성자: BoRaSaRang
> 배경: 공기계 USIM LTE 테더링 머신 운용 (A90 실측). v0.6 = DUN 탭 마무리, v0.7 = 라우터 가드 4종.
> 범위: A90 전용 (S22 검증 제외 — 2026-10-11 결정).
> 공통 규칙: `~/.config/opencode/AGENTS.md` + `AGENTS.android.md` 참조

## 1. 개요

- **목표**: SpotShift를 "IP 변경기"에서 "테더링 공유기"로 확장. 통신사 우회(DUN) + IP 로테이션 + 기기 보호(온도·전원) + 무인 유지.
- **방침 (확정)**: 신규 앱 분리 없이 SpotShift 확장. 라우터 가드들은 로테이션 주변 감시자라 단일 프로세스·단일 Shizuku 승인이 유리.
- **제약 유지**: 무루트/Shizuku (루팅은 v0.7 이후 별도 판단). TTL 직접 조작은 루팅 전용이라 v0.7 범위 밖.

## 2. A90 실측 반영 (2026-10-11, T-37 중)

| 항목 | 실측값 | 판단 |
|---|---|---|
| 충전 | 93% 방전 중 (미연결) | 운용 문제 — 전원 감시(F3)로 알림 |
| 발열 | thermal 4 (critical), 스킨 53~57°C, 배터리 39.9°C | 모뎀 스로틀 유발 — 온도 가드(F1) 필수 |
| 메모리 | free 130MB, swap 1GB 사용 | 백그라운드 킬 압력 — 생존 대책 포함 |
| 신호 | KT LTE RSRP -93, level 4 | 양호 |
| 핫스팟 | ROLE_SOFTAP_TETHERED 동작 중 | 정상 |
| DUN | 5744 type에 dun 유지 중 | 정상 (재부팅 시 리셋 가능성은 미검증) |

## 3. 결정 사항 (확정)

| 항목 | 결정 | 근거 |
|---|---|---|
| 확장 vs 분리 | **SpotShift 확장** | 단일 스케줄러·단일 Shizuku 승인, IPC 고장점 회피 |
| 권한 계층 | **추상화** (`PrivilegedShell` 인터페이스, 구현체는 Shizuku) | 루팅 전환 시 구현체 1개 교체. `ShizukuManager.runShell` 호출부를 직접 참조하지 않고 인터페이스 경유로 신규 코드는 작성 |
| 가드 실패 정책 | **페일오픈** (감시 실패해도 로테이션은 진행) | 기존 속도 검증(T-21) 원칙과 동일. 공유기 본분 = 끊기지 않기 |
| DUN 방식 | **직접 수정 + 재조회 검증** (복사-삽입은 S22 실측 후 판단) | A90 실측 성공. Android 14+ 차단 시 복사-삽입 폴백 추가 |
| 속도 감시 비용 | **패시브 우선(0바이트) + 판단 불가 시 미니 프로브 256KB** | 2G급 판정에 1MB 측정은 과소비. TrafficStats 실사용량 환산 → 불가 시에만 256KB 단일 측정 |

## 4. 아키텍처 (v0.7 추가분)

```
core/
├── PrivilegedShell.kt   # T-44: 셸 실행 추상화 (현재 구현=ShizukuManager 어댑터)
├── ApnController.kt     # T-37 (v0.6): DUN 조회·추가·원복 — PrivilegedShell 경유로 전환
├── ThermalGuard.kt      # T-40: thermalservice + 배터리 온도 조회, 임계 판단
├── PowerMonitor.kt      # T-41: 충전 상태·배터리 잔량 조회 (ACTION_BATTERY_CHANGED)
└── SpeedWatchdog.kt     # T-42: 주기 외 저속 감지 → 로테이션 요청. 절약 모드: 패시브(TrafficStats) 우선, 판단 불가 시 미니 프로브 256KB
receiver/
└── BootReceiver.kt      # T-39: DUN 상태 확인 + 미적용 시 재적용 (토글 연동)
ui/dun/                 # T-37 (v0.6): DUN 탭
scripts/
└── spotshift_status.sh  # T-43: 온도/IP/DUN/스케줄 원격 조회 (기존 rotate 스크립트와 짝)
```

> 로테이션 코어(RotationEngine/DataController/AirplaneController)는 손대지 않는다. 가드는 실행을 막는 조건이 아니라 연기·알림·기록만 수행.
