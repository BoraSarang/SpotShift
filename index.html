01왜 필요한가요

IP가 고정되면 생기는 일

장시간 핫스팟을 켜두면 IP가 고정되어 접속 제한·차단이 생깁니다. 직접 껐다 켜도 IP는 잘 바뀌지 않고, 바뀌어도 그 사이 연결이 끊깁니다.

주기마다 자동으로 변경

10분~24시간 사이 주기를 정해두면, 핫스팟이 켜진 동안 IP를 자동으로 바꿉니다. 변경 후 모바일 데이터와 핫스팟은 원래 상태로 복원됩니다.

루트 없이, 데이터는 밖으로 안 나감

Shizuku가 셸 권한을 빌려주는 방식이라 루트가 필요 없고, 중간 서버가 없어 데이터가 외부로 나가지 않습니다. 모든 처리가 기기 안에서 끝납니다.

02설치 방법

Play 스토어에 없는 독립 앱이라 과정이 조금 있습니다. 순서대로 따라 하시면 5분 안에 끝납니다.

1Shizuku

Shizuku 앱 설치 필수

SpotShift는 권한이 없는 앱으로는 통신을 바꿀 수 없어, 무루트 권한 시스템인 Shizuku를 함께 사용합니다.

  • Play 스토어: Shizuku (moe.shizuku.privileged.api) 검색 후 설치
  • GitHub (스토어 없이): RikkaApps/Shizuku 릴리즈에서 APK 다운로드
2활성화

Shizuku 활성화 무선 디버깅

갤럭시(One UI) 기준입니다. 다른 기기는 경로만 다를 뿐 순서는 같습니다.

  1. 개발자 옵션 켜기 — 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드 번호 7번 탭
  2. 설정 → 개발자 옵션 → USB 디버깅 ON
  3. 설정 → 개발자 옵션 → 무선 디버깅 ON → (팝업이 뜨면 허용)
  4. Shizuku 앱 실행 → "무선 디버깅으로 시작" 탭
  5. 페어링 코드 입력 — 설정 → 개발자 옵션 → 무선 디버깅 → 페어링 기기 쌍 연결에서 코드 확인 → 입력 → "항상 허용" 체크
  6. Shizuku 상단이 Running이 되면 완료 — 부팅 후에는 Shizuku 앱을 다시 열어 재시작해 주세요
💡 참고: ADB 케이블로 PC가 있다면 더 간단합니다 — PC에서 adb install 후 adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh 한 줄이면 끝납니다.
3SpotShift

APK 다운로드 + 허용

이 페이지의 APK 다운로드 버튼으로 app-release.apk를 받으세요. Play 스토어가 아니므로 "알 수 없는 소스" 허용이 필요합니다.

  1. 다운로드 페이지에서 app-release.apk 다운로드 — 한국·해외 어디서나 접속 가능
  2. 다운로드 완료 알림에서 APK 탭 → "이 앱을 설치할 수 없습니다"가 뜨면 설정 버튼 탭
  3. 갤럭시 경로: 설정 → 생체 인식 및 보안 → 기타 보안 설정 → 알 수 없는 앱 설치 → 사용 중인 브라우저 선택 → "이 앱 허용" ON
  4. 다시 APK 탭 → 설치 → 완료되면 열기
🔒 안전 안내: 허용은 선택한 브라우저 하나에만 적용됩니다. app-release.apk 외 출처 불명 APK는 설치하지 마세요. 정식 서명(릴리즈 키)으로 빌드된 파일입니다.
4시작

권한 연결 + 자동 변경 시작

  1. 앱 실행 → 하단 설정 탭 → "권한 요청" → Shizuku 다이얼로그에서 "항상 허용"
  2. 설정 탭이 "연결됨"으로 바뀌면 성공
  3. 홈에서 변경 주기 설정 (10분~24시간) → 셀룰러 전용 등 옵션 ON
  4. 기기 핫스팟 ON → 홈 자동 변경 시작 토글 ON
  5. 설정한 시각마다 IP가 자동 변경됩니다 — 예상 변경 시각은 홈 화면과 상태 알림에서 확인
🌏 해외(일본 등) 사용: 한국·일본 어디서나 동일하게 설치·동작합니다. IP 변경은 로컬에서 이뤄지므로 로밍 상태·통신사와 무관합니다.
03자주 묻는 질문
왜 Shizuku가 필요한가요?
권한이 없는 앱은 통신 설정을 바꿀 수 없습니다. Shizuku가 개발자 옵션의 디버깅 권한을 빌려줘, 루트 없이도 시스템 명령(svc data disable/enable)을 실행할 수 있게 해줍니다. 실패 시 에어플레인 모드 전환으로 자동 폴백합니다.
IP 변경 중 핫스팟 연결이 끊기나요?
변경 순간 수 초간 끊기며, 이후 자동으로 원래 상태로 복원됩니다. 데이터 재연결을 먼저 시도해 끊김 시간을 최소화합니다.
배터리나 데이터에 영향이 있나요?
IP 변경은 수 초간의 데이터 전환일 뿐이라 데이터 추가 소모가 거의 없습니다. 백그라운드 폴링 없이 설정된 시각에만 동작합니다.
업데이트는 어떻게 받나요?
같은 GitHub 릴리즈 페이지에서 새 APK를 받아 설치하면 됩니다. 같은 릴리즈 키로 서명되므로 설정과 데이터가 유지된 채 업데이트됩니다.
어떤 데이터를 수집하나요?
아무것도 수집하지 않습니다. 서버가 없고 모든 처리가 기기 안에서만 이뤄집니다. 네트워크 명령 실행 권한(Shizuku)만 사용합니다.
